# jiit-tt-parser
Parse JIIT Time Table Spreadsheets in Python

The functions defined in this library are used by CDN to generate structured data in JSON format from raw Excel sheets.

(CDN repo: https://github.com/codelif/jiit-planner-cdn)

The data from the CDN is hosted on: https://planner.codelif.in/

(Planner PWA repo: https://github.com/codelif/jpoop-planner)
